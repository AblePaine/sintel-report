## Ways to capitalize

- **Agent-checkout middleware for the long tail.** Walmart (via Muse) and Canva are opening up to agents while Amazon blocks them, and the 14% purchase success rate shows checkout is still broken. Sell mid-size retailers a drop-in "agent gateway" with account linking, approval caps and a structured catalog/cart API exposed over MCP. That is Walmart's model, packaged for everyone who can't build it.
- **Skills-as-plugins storefront play.** Claude now distributes skills and connectors as one plugin. Package vertical know-how (e.g., a desk/research or accounting SKILL.md plus its MCP connector) as a single plugin and list it now while the catalog is new and ranking is easy.
- **Harness arbitrage.** Artificial Analysis shows the harness changes cost more than the model does. Route each coding task to the cheapest harness/model pair that clears a quality bar. Cheap Apache-2.0 open weights (ERNIE 5.5 Flash, Ling-3.2-air) widen the spread.
- **PR-policy layer.** Claude Ship approves PRs "your team's policy allows." Whoever writes and audits those policies (compliance, SOC2 evidence, change-management logs) holds the enterprise relationship. Build the policy-as-code and audit trail that sits beside any merge bot.
- **Inference-specialist capital is flowing.** Marlowe ($277M seed) and the reported Amazon–Decart deal both reward chip-agnostic, model-specific inference. Small teams should build per-model serving optimizations (kernels, quant recipes for new open MoEs) as acquirable IP.
