## Ways to capitalize
- **Robotics API layer**: Dream-1 style zero-shot world-action models turn $2k arms into promptable tools. Build vertical apps (warehouse picking, lab automation, home service) on the API + fine-tune endpoint; sell the outcome, not the model. Displaces custom robotics ML shops and specialist integrators. Leverage is distribution of "prompt your robot" kits or marketplace of fine-tuned embodiments.
- **Agent observability stack**: Claude OTel is the first major lab shipping standard traces. Build agent-specific dashboards, cost anomaly detection, or eval pipelines on top of OTLP GenAI spans. Indie agents and MCP servers that export the same conventions get free enterprise credibility. Opportunity is the "LangSmith for MCP" or policy-enforced trace signer.
- **Agent identity + payments**: Binance [name].ai wallets are early reputation-gated surfaces. Build agent credential layers (x402-style payment rails + identity) that let agents hold balances and settle without human intervention. First movers who expose safe MCP + payment primitives capture the agent-to-agent commerce layer.
- **MCP hardening**: Plugin key-leak class of bugs is the new supply-chain attack. Ship audited, sandboxed MCP servers or a "trusted MCP registry" with static analysis. Security becomes a moat as agents touch money.
- **Indie agent tooling**: Herd Insights MCP and Hermes Meshy show framework vendors adding native agent surfaces. The leverage is shipping domain skills/MCPs that ride on existing local or open-agent stacks rather than competing with the big labs.
