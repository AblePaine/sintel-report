## Ways to capitalize

- **Directed open TTS as agent skill**: Drama 3 lets agents script, direct, and revise multi-character audio locally. Build voice agents, audiobook pipelines, or dubbing tools that own the generation layer instead of paying per-character to ElevenLabs. License threshold creates a window for sub-$500k shops. Displaces hosted TTS pricing power.

- **Local hardware MCP surfaces**: NVIDIA App MCP turns consumer GPU software into an agent-callable API. Same pattern for other desktop apps (OBS, DAWs, CAD). Ship thin MCP wrappers that expose high-value local actions without rewriting the app. Agents become the remote control for hardware/software users already own.

- **Domain science models as open infra**: CERN/Mistral-style Large Physics Model is the template for every specialized field. Build the data pipelines, evaluation harnesses, and fine-tuning tooling that turn domain simulators into agent-ready models. The money is in the vertical data + eval layer, not the base model.

- **Agent identity as the new auth layer**: t54-style credentials + risk limits for agents acting in finance (or any regulated domain). Productize permissioning, audit trails, and halt mechanisms so agents can hold wallets or execute without full user oversight. Displaces pure chatbot agents that can't be trusted with money.

- **MCP hardening as product**: Version pinning, credential redaction, sandboxing for MCP servers is now table stakes. Ship managed MCP gateways or security scanners that sit between agents and tool registries. The shadow IT problem is real; the fix is a product.
