## Ways to capitalize

- **Policy gateway is the product, MCP server is the commodity.** AAIF’s point is the 1997 ISP lesson: the protocol is free, the control plane gets paid. Build a relationship-scoped auth proxy (who, team, task, budget) that sits in front of any MCP server and refuses inherited user tokens. Enterprises will buy the deny-log, not another tools/list. The loser is the one-off internal MCP wrapper.
- **Own the harness, not the agent.** Omnigent’s shape says model vendors lose lock-in once sessions, skills, and permission policy live above the CLI. A builder wedge: a portable skill/policy pack that runs unchanged on Claude Code, Codex, and Agents SDK, plus a cost ledger. Campfire-style “who was right” diffs are the missing eval product — sell the race-and-diff, not another orchestrator.
- **Waiting-on-human is a distribution surface.** Agent Lookout is a local page. The business is a hosted inbox for agent blockers (approval, missing credential, failed tool) with a mobile push. Whoever owns the interrupt owns the daily habit.
- **Do not pre-build on the Reflection rumor.** If a US open frontier weight actually lands, it undercuts API margin at labs still selling raw tokens (OpenAI/Anthropic coding plans, Chinese API resellers) and hands margin to whoever already has the deployment inside the bank or ministry. Prep the fine-tune and eval harness; do not price a product on an unreleased card.
- **Humanoid leverage is the open stack, not the dance video.** RP1-style full-stack open hardware is the PC clone moment. Money is in task-specific skills, sim environments, and end-of-arm tooling for one vertical (warehouse tote, lab sample), not in another biped OEM.
- **Agent money is a base-URL and a checkout, not a new chain.** WalletConnect-style pay-from-balance-already-in-the-wallet plus Surplus-style SDK base-URL swap is the rail. Build an agent identity that can top up, pay a tool call, and pass sanction/Travel Rule checks without a human modal. GPU-backed stablecoin yield (sUSDai) is a financing wrapper on scarce compute — the durable piece is the offtake contract, not the token.
