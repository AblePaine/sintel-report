## Ways to capitalize
- **Memory scarcity is now a multi-year constraint, not a cycle.** If DRAM stays rationed into 2028, the leverage goes to anything that cuts memory per token: KV-cache compression, small-active-param MoE models served locally, and context-diet tooling. The Codex 80% payload cut is the same move at the API layer. Build a "token/byte diet" proxy that dedupes tool catalogs and trims context for any agent, and sell it on measured savings.
- **Sandbox router = the picks-and-shovels gap in agent infra.** Model routing is commoditized. Execution routing isn't yet. Whoever owns the unified sandbox API also owns billing, the audit logs and the security posture for agent code. This is a small-team build with a clear wedge: route by price and cold-start time, then add policy and logging and charge enterprises for them.
- **Legal wrappers for agent-run businesses.** Whether Delaware's bill lands in January or not, the "agent as operator" entity is coming. The opportunity is formation-as-a-service: entity setup, action logging that meets the draft's record-keeping duty, and agent-held payment and stablecoin accounts. Treat it as early; it's a draft.
- **OpenAI vs Apple is a hardware supply-chain fight.** Supplier coercion claims mean OpenAI's device effort is real enough to fight over. Contract manufacturers and component makers that can show they're neutral gain leverage, and so do indie hardware builders who sell to both sides.
