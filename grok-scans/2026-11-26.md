## Ways to capitalize

- **Token cost is now the product spec.** OpenAI's quiet 25–40% usage cut on its best models, plus TokenEconomizer and model routers, all say the same thing: teams will pay for *cost per finished task*. Build the meter: a drop-in proxy that charges per agent run, flags re-runs and context bloat, and routes sub-tasks to cheaper models automatically. Sell it to eng managers with a Codex/Claude bill, not to developers.
- **Models are becoming tools that other labs' agents call.** Google pitching the Gemini CLI to Claude Code and Codex users means "best model per sub-task" delegation is now endorsed by a lab. The leverage is a cross-vendor subagent skill pack (image gen → Gemini, long refactor → Astra, cheap bulk → open weights) with a cost/quality scoreboard. Whoever owns that routing table owns the agent's spend.
- **MCP auth is the soft underbelly.** Tokens bound to a server name instead of its URL are a design-level bug class, and Google is about to *require* MCP for Workspace. Build an MCP auth gateway that binds tokens to origin, logs every token use, and re-asks for consent on URL changes. Sell it to security teams as "agent SSO hygiene". A free scanner that audits local MCP configs is the wedge.
- **Robot data moats are moving into simulators.** Sim-only post-training that transfers to cheap arms (RoboRSI on Piper), plus tactile-first models (Lute), shrinks the need for teleop data farms. Opportunities: task-specific sim environments and evals for $3–10K arms, and integrator kits that bundle an open VLA, a tactile sensor and a skill library for one vertical (retail restock, kitting).
- **Agent infra is consolidating into the inference clouds.** Baseten–Blaxel and Amazon–Decart show sandboxes, runtimes and optimization stacks getting folded into whoever sells the GPUs/chips. Independent agent-infra startups should either go deep on a niche the clouds won't touch (compliance-grade sandboxes, on-prem) or build to be bought. Displaced: standalone "agent hosting" without a compute margin.
