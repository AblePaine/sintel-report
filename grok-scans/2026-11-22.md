## Ways to capitalize

- **Delegated-credential insurance and scoped agent wallets.** The banks just pushed all agent risk onto the user, and AWS just showed agents can pay without holding money. The gap is a consumer-grade "agent card": capped, merchant-scoped and revocable, with an audit log that holds up in a dispute. Whoever issues it (a fintech, or a stablecoin rail with chargeback-like escrow) captures agent commerce that the banks just refused to underwrite. Screen-scraping finance agents are displaced; they now carry uninsurable liability.
- **Sell to agents through AWS billing, not crypto.** x402 on AWS Marketplace means a data or API seller can get paid per request by enterprise agents on an existing AWS PO. Wrap a niche dataset (filings, sanctions lists, pricing feeds) as x402 endpoints now, while the catalog is thin. The early listings become the default ones agents find.
- **Framework-owned skills become a moat, so become the skills auditor.** NestJS and Vercel are shipping first-party SKILL.md packs. A neutral layer that tests, versions and scores skills against real bugs (a CI for skills) is unclaimed. That's where "skills marketplace" money goes once every framework has one.
- **Knowledge-factory tooling for SMBs.** LangChain's curator/gardener pattern is an internal practice, not a product. Package it as a "company memory gardener" that watches docs, Slack and repos and keeps agent context current. Sell it to the 50–500-person companies that can't build it.
- **Vendor-portability as a service.** If Amazon pays ~$7.5B for chip-agnostic inference (Decart), independent cross-accelerator optimizers are next. Builders running on rented GPUs should design for TPU and Trainium portability now; that's where the price cuts will come from.
