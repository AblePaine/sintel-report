## Ways to capitalize

- **Agent egress is now table stakes.** Claude Code's email leak proves model-context PII will leave via tool calls the harness never intended. Ship a local egress firewall + audit log for coding agents (deny User-Agent/contact injection, redact session identity, log every outbound host) and sell it as a one-line install for Claude Code / Codex / Cursor teams. The privacy mod's holes are the product brief.
- **Parallel-agent orchestration has a two-week vacuum.** Conductor Cloud dies Nov 20. Build a model-agnostic local orchestrator (Claude Code + Codex + Cursor workspaces, PR merge queue, human review gate) and market a one-click Conductor import before Nov 20. Meta will reappear in early 2027; the interim window is the sale.
- **Cited web answer is a managed MCP commodity.** AWS prices Web Answer at a cent a call. Wrap it (or an open alternative) as a drop-in MCP server with domain allow/deny lists and per-tenant billing for indie agents that can't or won't sit on Bedrock. Undercut DIY search-RAG stacks.
- **Defender-only cyber agents are a channel.** GPT-6 Cyber is Daybreak-gated. Package a managed "authorized vuln find + patch PR" service for mid-market OSS and SaaS that can't get Daybreak Red themselves — human sign-off on every exploit and patch. Pair with the $1,300/kernel-bug economics from Nov 4.
- **On-prem CX AI is still buyable.** Five9 is paying $325M to keep Level AI runnable on someone else's contact center. For vertical CX (health, fintech, gov) that won't move to CCaaS yet, sell Latitude-class conversation models + agent-assist as a sidecar, with a migration path when they finally cloud.
