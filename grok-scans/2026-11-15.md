## Ways to capitalize

- **Sell "MCP-ification" to mid-market SaaS.** Bustamante's thesis gives every vertical SaaS company a reason to ship a hosted, permissioned MCP server, and most lack the team to do it. The play is a productized service or platform that wraps an existing SaaS API in scoped tools with audit trails and per-tool billing, so the vendor gets usage revenue back. Displaced: the bolt-on "AI assistant" teams burning margin on tokens.
- **Managed agent operations is a real category.** Agents break silently when an ERP field or invoice format changes. Build agent ops: monitoring for drift and outcomes, replayable traces, permission reviews and integration upkeep, sold per agent per month like managed IT. Early buyers are firms already running dozens of agents.
- **Agent-speed defense for the edges.** ARTEX targets peripheral systems (partner portals, mobile backends, forgotten business-unit apps) and leaks exposed cloud credentials. An exposure scanner that thinks like ARTEX, inventorying a company's long tail of internet-facing apps and secrets continuously, can be sold now with the FBI FLASH as the sales deck. Egress monitoring for LLM API calls from servers that shouldn't make them is a cheap wedge.
- **The coordinator layer is up for grabs.** Anthropic is turning Claude Code into a coordinator over parallel cloud threads, and indie tools already run Claude Code, Codex and Gemini side by side. A vendor-neutral coordinator that routes each thread to the cheapest capable model is the leverage point, as long as it shows cost per thread, since every parallel thread burns quota.
