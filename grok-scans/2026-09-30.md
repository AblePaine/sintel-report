## Ways to capitalize

**1. KYA is the new SSL.** Beltic, Rig, MoonPay Agents, NIST receipts — four independent bets that *identity + spend envelope* is the missing packet header. Do not build another personal agent. Build the thing merchants and banks call before they honor one: a credential format + a one-call allow/deny + an audit trail a card network can live with. If Beltic is Stripe-for-agent-identity, the wedge is a plugin for whoever already owns checkout (Shopify, DoorDash, Square), not a dashboard for AI startups.

**2. SMS / iMessage is the consumer OS. Apps are becoming backends.** DoorDash, Lucas, Instinct, DashBuddy — none of them need a new icon. If you have a recurring local service (beef drops, farm CSA, booking, parts), the product is a textable agent with a stored pay method and a hard spend cap, not a site. DoorDash just published the office-ordering MCP shape; copy that contract for any catalog that already has SKUs + delivery.

**3. Durable execution is getting priced as a default, not a Temporal tax.** Restate at $20M vs Temporal at $12.55B is the 1997 Apache-vs-WebLogic setup. If you ship agents that book, pay, or mutate ERP, the runtime that survives a mid-tool-call crash *and* does not double-charge is the product customers will pay for. Thin wrapper: Restate (or Temporal) + Beltic-style check at every money tool call.

**4. Who gets displaced.** (a) System-integrator bodies on SAP/Salesforce tickets — Dodge’s explicit target; even if the seed is small, Accel + Google showing up means the $600B maintenance stack is now an agent category. (b) Figma/Canva as the *starting* canvas for commodity motion — Tesseract. (c) The DoorDash/Uber app tax on “I already know what I want” orders — text agents. (d) Human-or-bot CAPTCHA vendors — the question moved to authorization.

**5. Builder move this week, not this year.** Ship one MCP that does a real checkout or a real booking with: principal credential, spend receipt that does not clone on retry, and an iMessage/SMS front door. That is the 1997 homepage. Everything else is a theme pack.
