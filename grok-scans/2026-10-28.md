## Ways to capitalize

- **MCP hardening layer**: The command-injection wave is a distribution moment for a trusted MCP gateway or policy engine that intercepts tool calls, enforces schema + sandboxing, and signs tool definitions. Builders who ship audited, low-priv MCP wrappers or a "MCP firewall" (capability tokens + re-validation on update) can become the default safe surface while raw servers get blocked by enterprises and cautious indie users. Displaces unvetted community servers.

- **Local agent runtime + distribution**: Cloud agents are handing over the keys. A lightweight local agent harness (with MCP but sandboxed, credential isolation, and easy skill install) that syncs only what the user explicitly allows has a clear wedge against Muse/Claude/Grokbot. Monetize via premium skills, private model routing, or hardware partnerships. Early movers own the "my data never leaves" category.

- **Autonomous shipping infrastructure**: Shipfun's model (user brings the model key, platform handles schedule/grade/deploy/public proof) points to the next layer after coding agents: outcome-as-a-service for indie and small teams. Fork the pattern for specialized verticals (SEO, support, research) or build the grading/rubric marketplace. Displaces traditional freelance marketplaces and agency retainers for routine shipping work.

- **Exploit discovery as a product**: Anthropic's result shows frontier models can already produce usable multi-step exploit chains with light prompting. Red-team-as-a-service or continuous agent-driven fuzzing for browser/OS/mobile stacks becomes a high-margin offering for labs and security firms. Builders can package this as a service that feeds vendors (and charges for early access to findings).

- **Open-weight routing & specialization**: Token volume is already on open models even while capability scores lag. Opportunity in thin routers, domain-specific fine-tunes, and agent skills that make the cheaper open models good enough for high-volume tasks (search, coding boilerplate, content). Capture margin between closed API pricing and open inference costs.
