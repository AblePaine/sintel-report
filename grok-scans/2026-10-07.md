## Ways to capitalize

- **PAP is a door, not a protocol yet.** v0.1 is unpublished and has no license or foundation. The leverage is a reference merchant endpoint that speaks guest + OAuth scopes over MCP/OpenAPI before Sierra’s own brand agent becomes the default implementation. Whoever ships the first non-sponsor write action (Kerr’s Jan 4 2027 test) sets the de facto lock. Displaced: screen-scraping computer-use shops, and any checkout that assumes a human session.
- **Metered cloud is the agent billing primitive.** Alibaba x Sui makes the invoice the thing that dies. Build a per-call stablecoin meter in front of any API you already run (inference, browser, retrieval) so an agent can pay without a human card on file. Displaced: monthly SaaS seats and prepaid credit buckets that agents cannot top up themselves.
- **Open-weight schedule is the short.** Mistral 1T and Reflection Beam are promises, not weights. The trade is not “host the 1T.” It is tooling that assumes the weights arrive: air-gapped eval harness, quantization, and a router that swaps closed API calls for local MoE the week the files hit Hugging Face. If the drop slips, the closed labs keep the margin. If it lands, API list price on bulk generation is the demand that gets destroyed.
- **Decisions API vs Responses API.** If typed, fast decision calls are real, agent loops should stop using a chat completion as a control plane. Thin wrapper that emits a schema, retries on type failure, and logs the decision — that is the product, not another chatbot. Displaced: prompt-engineered JSON parsers.
- **Evented MCP, not cron.** runneth’s pattern (hand off, sleep, wake) is the missing half of agent infra. A small event bus that any MCP server can fire into is more defensible than another scheduler. Polling agents are the 1997 CGI script.
