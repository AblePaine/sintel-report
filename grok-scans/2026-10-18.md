## Ways to capitalize

- **DeepSeek 1017 as default agent worker**: Build Claude/Codex-compatible harnesses that route sub-agents or long loops to Flash-1017 (same price, better agent scores, open weights). Demand destruction for mid-tier paid tokens; leverage is in the orchestration layer and local fine-tunes, not the model itself.
- **Agent-safe surfaces & licensed proxies**: Sites are closing the open web to agents. Build or sell MCP wrappers / licensed data brokers that agents can pay for (x402/stablecoin) instead of being blocked. Distribution shifts from free scrape to paid, authenticated agent endpoints.
- **Local MCP security wrappers**: NVIDIA App (and similar) now expose control planes by default. Ship lightweight permission proxies, audit logs, and kill switches for consumer local MCPs. Who owns the agent-on-device trust boundary captures the consumer distribution.
- **Runtime agent credentials**: ServiceNow Passport is the enterprise version. Indie/open equivalent: portable signed capability tokens for agents that any MCP or payment rail can verify. Build the open standard before the closed ones lock it.
- **Agent wallets with policy engines**: The PayBox hacks show demand for spending tests, escrow, and private balances. Ship opinionated agent payment kits (budget, dispute, verification) that sit above raw wallets. The leverage is in the policy + verification layer, not the chain.
- **Displacement map**: Junior coding/research labor compressed fastest. Build tools that let senior judgment + agent fluency capture the margin that used to go to headcount. The 1997 play is owning the agent-native interface to an existing workflow, not another chatbot.
