## Ways to capitalize

- **Local agent stacks on Muse Spark / open weights**: Build opinionated on-prem agent frameworks that pin to Muse Spark (or DeepSeek Flash) + MLX/llama.cpp on Mac Studios or workstations. Target regulated verticals (PHI, finance) where cloud inference is blocked. Displacement: OpenAI/Anthropic API spend and Chinese model distributors. Leverage is eval harnesses against real query logs + write-gating, not the weights.

- **MCP servers for physical/infra ops**: DE-CIX pattern generalizes. Ship MCP servers for any operational surface (cloud accounts, on-prem hardware, SaaS billing, IoT). Charge for the connector + audit log + human-in-loop gates. Agents become the UI; the MCP host captures the fee. Displaces custom integration shops and dashboard-heavy tools.

- **Agent skill marketplaces and consent layers**: Package domain skills as SKILL.md + MCP with built-in review/consent (Room Service style). Distribution via agent directories. Who makes money: skill authors and the consent/identity layer, not the base model. 1997 web analogy — the browsers were free; the real money was in the directories, payment rails, and trusted intermediaries that made the new surface usable and safe.

- **On-device / local inference displacement**: As frontier-class open models run on dual Mac Studios, the marginal cost of agent work collapses. Build vertical agents that never leave the box. Business model shifts from token markup to software license + support + data connectors. Labs that only sell API access get squeezed; hardware + local software + eval win.
