## Ways to capitalize

- **Skill/MCP linting is a product now.** Invisible-Unicode payloads + ~thousands of starred skill repos = a scanner that strips/flags Tag chars, hidden prompts and shell calls before install. Ship as a pre-commit hook, a GitHub Action, and a registry badge ("scanned clean"). Whoever owns trust for skills owns the skill marketplace.
- **Sandbox-as-a-service for always-on repo agents.** dsh-superagent's own docs say "use a dedicated OS account." Package that: one-click per-repo VM/container with scoped GitHub creds, egress allowlist and a kill switch. Sells to every team trying DeepSeek, Codex or Claude background agents.
- **Agent-launchpad rails are coming, so build the guardrails side.** If agents can mint coins over MCP, there's demand for rate limits, provenance (which agent, whose wallet) and rug detection on agent-launched tokens. Reputation-gated launch MCPs beat open ones.
- **Don't build on one plugin store.** The jwbobbink thread is the 1997 portal lesson: use LLM directories for acquisition, but own the email/account relationship from day one. For buy-once offline apps this is the pitch: no platform can switch you off.
- **Sovereign AI capital is flowing to compute, not apps.** HUMAIN (3 GW) and OpenAI's UAE-led round mean Gulf money funds the infrastructure; the app layer on top (Arabic-first agents, energy/industrial ops agents) is underbuilt and will get the API credits.
- **Nov 4 Kimi weights = cheap self-hosted coding.** Line up a "run K3.1 Pro on your own box" guide/installer before Wednesday; demand spikes the day weights drop.
