## Ways to capitalize

- **SKILL.md is now Apple's format.** One skill file now works for Claude Code, Codex, Hermes and, from spring, Siri on every iPhone. Build a "skills compiler" that takes an app's App Intents and API and generates and tests SKILL.md bundles for Siri and the coding agents in one go. Sell it to the long tail of iOS devs, who have about a 4-month window before App Store submissions open. The losers are app-specific voice and assistant SDKs.
- **Vulnerability discovery just got priced.** About $1,300 per validated, patched kernel bug resets bug-bounty and pentest economics. The opening is a managed "autonomous patch" service for mid-market Linux and embedded vendors who can't run this pipeline themselves: offered by retainer, with human sign-off on each patch. Bounty platforms paying per-bug human rates get squeezed first.
- **Local frontier coding is real.** Ripple-65B on a MacBook plus Kimi K3.1 Pro weights means a regulated shop can run near-frontier agentic coding with no data leaving the building. Package it as an on-prem coding-agent appliance (DGX Spark or Mac Studio, a preloaded model, and a skills library) for law, defense and healthcare IT. That undercuts seat-based cloud coding tools in those verticals.
- **Data-center permitting is the new moat.** OpenAI is volunteering the rules (pay full grid cost, publish water and noise data, no NDAs with officials) and asking for them to become law, which raises the bar for smaller builders. There's a services gap in per-site community-compact reporting: water, noise and jobs dashboards for the developers who will now be expected to match it. Sell to neoclouds and colos.
- **Cross-border robotics M&A is closing.** After Manus and now ABB, foreign buyers can't take China-heavy robotics or agent assets. That makes non-China industrial-robot makers with clean data supply chains more valuable to acquirers like SoftBank. The builder angle: robot fleet data pipelines that stay inside one jurisdiction will be a requirement in every deal.
