Ship the same shape for internal registries (npm, pip, Maven, container bases): facts + CVE + policy, zero write. The money is the policy server, not the model. Displaced: agents that `pip install` on vibes, and the security review that blocks them.

Build the budget/receipt layer (per-agent cap, receipt, revoke) and sit between every MCP that can spend. Displaced: human ticket queues for GPU and the hyperscaler console.

- **Distribution is the MCP manifest.** PostRoutine and komori are the same bet: one safe tool surface, every host (Claude, Codex, Cursor) gets it free. 139k servers means discovery is the scarce layer. A ranked, permission-labeled index (who can spend, who is read-only, who needs a key) is the 1997 Yahoo of this stack. Do not build another server. Build the filter agents already ask for.
