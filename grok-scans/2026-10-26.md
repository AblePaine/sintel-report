## Ways to capitalize

- **Government / public data MCPs**: TCMB is the pattern. Build vertical agents and skills that consume official MCP data feeds for economic monitoring, trading overlays, compliance checks or localized research. First quality interface + evaluation layer on new public MCP surfaces captures the agent traffic; labs and closed platforms do not own the data. Replicable as more central banks and statistical agencies ship MCP.

- **Portable skills economy**: With Agent Skills standardized under AAIF, the unit of distribution shifts from model-specific prompts to portable skill packages. Ship high-value skills (financial modeling, code review, ops runbooks, domain research) once and list across every supporting agent runtime. Quality, reliability and reputation become the moat; pure model lock-in weakens. Opportunity in skill marketplaces, skill evaluation harnesses and domain-specific skill packs that undercut generalist agent subscriptions.

- **Agent trust, identity and payment gates**: Tools like TWZRD Trust signal demand for lightweight checks before agents spend stablecoins or call paid endpoints (x402 etc.). Build reputation systems, credential issuers, policy engines or agent credit scores that other agents can query. Who controls the allow/warn/block layer for agent-to-agent or agent-to-service commerce takes a cut of the flow without holding the capital.

- **Open weights + agent infra vs frontier capital**: Meta’s dilution and Anthropic’s IPO underscore that frontier capability is extremely capital intensive. Mistral’s open weights (and similar) plus standardized MCP/skills let builders deliver specialized workflows at lower cost and with full control. Leverage is in narrow, high-value agent products on open models rather than competing on general frontier. Displaces a slice of API spend and creates room for indie distribution.

- **Voice / telephony as primary agent surface**: Grok Bot calling people expands agents from chat to real-world coordination. Opportunity in reliable orchestration skills for phone + email + calendar, verification layers so agents do not get scammed, and agent-to-agent voice protocols or safe-haven networks that reduce reliance on any single lab’s telephony feature.
