## Ways to capitalize

- **Eval-as-a-service for the skills economy.** GitHub just made evals for skills, agents and MCP a first-class workflow, but only inside Copilot. Build the cross-client version: a hosted eval suite that scores any SKILL.md or MCP server on Claude Code, Codex and Cursor, and publishes a badge. Pair it with a registry and you own the trust layer. Displaces: "it worked on my prompt" marketplaces.
- **Agent checkout is live, so the money is in limits and consent.** Zinc's MCP (with `max_price` and idempotency) plus Barr's warning about unverifiable agent actions (Fed speech, Nov 16) point to the same gap: a spend-policy and consent proxy between agents and payment rails, covering per-action approval, caps and an audit trail. Sell it to agent builders now, then to banks once regulators require it.
- **Cheap open weights versus a disclosure rule is a hedge market.** Hy4 Flash at 12B active is near-free to serve, but a US disclosure rule would make "which model is behind this?" a compliance question. Build a model-provenance and routing layer that auto-swaps Chinese weights for US or EU equivalents per customer policy and emits the disclosure. Every SaaS running Qwen through OpenRouter becomes a buyer the day the rule lands.
- **AI assistants are the new SEO.** A jump from 25 to 590 signups a week via Claude and ChatGPT is one claim, but it matches the Product Hunt MCP pattern from yesterday. Offer a "GEO + MCP" package for niche SaaS: a structured docs page, an MCP endpoint and assistant-citation tracking. Displaces: link-building agencies.
- **Data center capex is fine; the PC is the squeeze.** NVIDIA guides +$14B q/q while saying memory prices are hurting consumer PCs. Local-first agent products should target existing hardware (12B-active MoE fits), not assume new rigs, while cloud-agent margins keep improving.
