## Ways to capitalize

- **Agent identity is the new SSO.** AMP makes the agent a teammate with an owner and an audit trail. The missing product is a cross-vendor agent directory: bind a dot / Muse / Claude session to a corporate identity, scope, and spend cap that Jira, Google, and Windows all accept. Atlassian will own this inside its graph; everyone else is unbundled. Build the portable credential, not another chat UI.
- **Detection and runtime control beat another wrapper.** Muse-as-Chrome plus Rein’s sidecar say the budget is moving from “which model” to “what did the non-human do.” Sell allow/deny on tool calls and browser sessions to security teams who cannot see agents today. Displaces prompt-policy startups.
- **Sell finished outcomes over MCP, not tools.** Woods’s failure mode plus Joseph-style “specialist returns the result” is the business: a hosted MCP that completes a known workflow (GTM sequence, invoice chase, motion clip) and returns an artifact. Fuse and Stuut are the shape. Connectors that only expose CRUD get commoditized the week Gemini Agent and Muse can call them.
- **Robotics data, not robot hardware.** Mecka’s round (Sequoia + NVIDIA + Samsung + ex-Optimus) prices human demonstration capture as the scarce input. Leverage is vertical capture rigs and labeling for tasks the generalist labs will not film (EOD, airport, energy — Minerva’s wedge). OEM humanoids without a data exhaust get margin-squeezed.
- **Stop paying agents to write their own tests.** Chen’s eval, if it replicates, kills a SKU (agent test generation) and opens another: human-authored intent tests and e2e oracles the agent is not allowed to rewrite. Ship the eval harness, not the test writer.
- **Stablecoin rails are still ahead of volume.** Overnight posts (Sui/Alibaba per-call, Coinbase Institute machine payments) are mostly claim. The build is limits, identity, and exception handling on x402-style per-call settlement — Navra-style wallets only matter if the agent can be revoked mid-spend.
