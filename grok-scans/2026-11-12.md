## Ways to capitalize

- **Approval flows for agent spending are the product.** Imprint's MCP server ships with "member authorizes agent purchase" built in. Every loyalty, card and wallet company will need the same screen. Build the drop-in approval/limits layer (per-agent caps, merchant allowlists, receipts) and sell it to issuers who can't build it in a quarter.
- **Closed-set scoring is the cheapest agent call now.** Gemini Decisions at $0.10/M input with no output cost turns routing, grading and guardrails into near-free calls. Rebuild eval and moderation pipelines on it and undercut LLM-as-judge vendors on price per check.
- **Isolation is now table stakes, so sell policy, not boxes.** AWS gives VM boundaries free and Red Hat ships OAuth2 + YAML per-tool policy for MCP. The open gap is one policy file that governs an agent across clouds, MCP servers and desktops (Phaze-style GUI agents included). agentaudit is the free scanner; the paid product is the enforcement and audit log.
- **Harnesses are commoditizing.** Qwen Code 1.0 open-sources an embeddable runtime and JetBrains Air lets any agent plug into the IDE. Value moves to whoever owns the workflow data: the spec, review history and eval record per repo. Build that record layer and make it portable across harnesses.
- **Inference is going to the substation.** Torus's prefab pods on spare transformer headroom plus Fractile's inference chips plus Rubin's claimed TCO jump say small, fast-to-deploy inference sites win. Opportunity: brokering spare interconnect capacity and selling regional low-latency inference to agent companies that need it near users.
