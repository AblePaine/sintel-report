## Ways to capitalize

- **Open weights that are actually near-frontier (Kimi Nov 4)**: Demand destruction on closed API premiums. Build fine-tunes / specialized agents that run on your own infra at $2/$10 equivalent or less. Port Agent Skills + MCP servers to the open model the day weights drop. First-mover on private, regulated, or high-volume agent workloads that refuse to send data to OpenAI/Anthropic/Google. Leverage: local/private inference stacks, eval harnesses that match Terminal-Bench style tasks.

- **Skills layer is now infrastructure**: The valuable part is no longer the protocol but the content of SKILL.md (domain exceptions, checklists, failure modes). Ship high-quality, versioned skill packs for verticals (finance ops, legal review, robotics teleop, crypto research). Marketplace or reputation layer for skills (who published, who verified). Distribution: Cursor / Copilot / Claude / ChatGPT all load them. Undercuts pure prompt engineering shops.

- **Tactile robotics gap**: Enact (and similar) bet that force sensing beats pure vision for real factory work. Opportunity in force-aware simulation, data collection pipelines, or software that turns motor torque into training signals. Software-only plays: world models / JEPA-style that incorporate force. Hardware remains hard; software and data moats are reachable for indies.

- **Local agent control surfaces**: NVIDIA App MCP, Firebase CLI MCP, OmniGEO MCP, etc. The surface area of what agents can touch is expanding fast. Build MCP servers for tools that still require humans (design apps, local hardware, private data stores). Or safety layers / killswitches for the ones that already exist. Business model: agent-consumable SaaS (pay per tool call or subscription that agents can auth against).

- **Enterprise multi-model routing + perimeter**: Google (and others) making every frontier model available under one invoice and IAM. Money moves to routing layers, cost-per-task optimizers, and audit trails. Build the “which model for this task + which cloud perimeter” middleware. Displaces pure model lock-in.

- **Agent money rails**: Still early. Concrete leverage is identity + escrow standards that let agents hire other agents or settle without a human bank account. Watch ERC-8004 style and stablecoin spend limits. Build reputation-gated marketplaces or TEE-attested delivery proofs before the big platforms do.

Nothing massively breaking in the last 4 hours beyond the Kimi coverage and the Skills foundation move already circulating. The leverage is in the open near-frontier model + the portable skills layer + local control surfaces.
