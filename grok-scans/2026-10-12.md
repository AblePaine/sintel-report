## Ways to capitalize

- **MCP gateway layer**: Build the "don't be Uber" product — opinionated, self-hosted or hosted compact meta-tool gateway with OpenAPI import, policy profiles, Code Mode, and agent-native discovery. Sell to the 99% of teams that will otherwise drown in tool context or rebuild poorly. Distribution via Claude Code / Cursor configs.

- **Physical AI data + actuator adjacency**: DeepSeek/Figure pattern shows compute is table stakes; the scarce inputs are real-world interaction data and actuator/rare-earth supply. Indie angle: high-quality, rights-cleared first-person task video pipelines or specialized actuator software/firmware stacks that OEMs will buy rather than build. Undercuts pure model API margins further as value moves to the body.

- **Personal agent distribution**: Muse and Chinese equivalents (Ant Lingguang) signal consumer personal agents are the form factor labs are betting on outside coding. Build the skill/MCP layer and reputation graph that agents will need to transact (payments, identity). Early movers on agent-to-agent commerce rails capture the new "who makes money" layer once agents hold wallets.

- **Open-weights inference ops**: Mistral Large 4 and peers compress closed-lab pricing power. Opportunity is in fine-tuned verticals, local/edge serving, and the tools that make open models production-grade for agents (eval harnesses, tool-use fine-tunes, private hosting). Hyperscalers and neoclouds win the base; builders win the application and routing layer.
