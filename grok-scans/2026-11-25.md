## Ways to capitalize

- **Ship skills from the server, not the store.** Skills over MCP means any SaaS with an MCP server can push per-account playbooks that update with the server and need no install. That's something a static plugin can't do. Build "skill-ops" for B2B SaaS: generate tenant-specific skills from a customer's config and usage, version them, and eval-gate them. Shopify/HubSpot/Atlassian did it by hand; the next 5,000 MCP servers will want it packaged.
- **Elicitation + agent IDs = the approval layer.** GA Elicitation (sign-off before spend or delete) plus CAIS's accountable agent IDs gives you the parts of a merchant-side "agent trust gateway": verify which principal an agent belongs to, apply spend/risk caps, and ask the human mid-call. Sell it to the retailers and fintechs now deciding whether to block or admit agents.
- **Installed-artifact apps are a new micro-SaaS channel.** Claude artifacts that install as desktop apps and use connectors turn prompt templates into distributable utilities. Package niche vertical tools (e.g., a desk dashboard, a seller fee calculator) as shareable artifact apps plus a SKILL.md, before a marketplace forms and ranking gets hard.
- **Cheap specialist fine-tunes beat frontier APIs on narrow tasks.** Mantic (7% of cost via Inkling 2 Small + Tinker) and the 4B OCRia-1 point the same way: an open small model, fine-tuned plus a harness, wins narrow vertical work. Pick one high-volume document or forecasting workflow and sell it as a flat-rate service that undercuts per-token frontier pricing.
- **Backtest-safe environments are infrastructure.** Epochal's leakage-free "past web" is what forecasting and trading agents need for honest evals. A smaller builder can do the same for one domain (crypto/on-chain state or filings, point-in-time) and sell it as an eval harness to desks and agent builders.
