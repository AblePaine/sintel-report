## Ways to capitalize

- **Terra price/performance step**: Build thin agent wrappers or vertical computer-use skills on the new cheaper mid-tier (and Bedrock). Sell the outcome (form filling, multi-app workflows, content + action loops) not the tokens. Displaces higher-margin closed API usage for routine work; capture the distribution via skills / hosted agents.

- **Open-weights + inference race**: Host or fine-tune abliterated / high-capability open models for verticals that need zero-guardrail or on-prem. Or sell the infra layer (optimized serving, evals, enterprise SLAs, memory/GPU allocation tools). Closed labs lose margin; inference operators and hardware-efficient stacks gain.

- **Agent payment rails**: Wrap existing tools/APIs as paid MCP servers or x402 endpoints (proprietary data, reliable integrations, domain skills). Agents will pay for what they cannot cheaply recreate. First movers own the micro-transaction surface before platforms lock it.

- **Agent-consumable surfaces**: Auto-generate MCP from OpenAPI / docs / internal APIs (extend mcpsmith-style). Or build reputation / identity layers so agents can safely call each other and pay. Displaces manual integration shops; rewards anyone who makes a surface agent-native first.

- **Humanoid supply chain**: Track component / order flow into China factories; opportunity in software layers (skill transfer, simulation-to-real, agent control of physical systems) rather than pure hardware. Hardware OEMs scale; software and integration capture recurring value.
