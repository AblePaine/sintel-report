## Ways to capitalize

- **Lean-verified work as a product category.** RH proved that "agent writes it, the kernel checks it" scales to 17M lines. Apply that to things buyers already pay to verify: smart-contract audits, tax and compliance rules, safety-critical control code. Sell a certificate the kernel produced, not a model's opinion. Code-audit shops that charge by the hour are the ones displaced.
- **Agent-earned income needs payroll plumbing.** Visa CLI makes agents earners, with a card used for KYC and stablecoin payouts. Missing pieces: 1099/tax reporting for agent earnings, a reputation score that follows an agent between marketplaces, and dispute escrow. Whoever builds the "Gusto for agents" owns the user relationship.
- **Agent security becomes the security market.** CrowdStrike paying $43.9B for the network layer means agent traffic (MCP calls, browser agents, credential use) will get inspected inline. Point products that only govern agent identity or MCP access are now acquisition targets or roadkill. Build the policy/telemetry layer that plugs into Falcon and its rivals, not a standalone console.
- **Workstation-GPU sovereign stacks.** Sarvam's NVFP4 weights run on one RTX PRO 6000, and LingSante is open. Ship turnkey on-prem boxes for Indian enterprises, hospitals and law firms: model, agent runtime and audit log on one GPU. Cloud API vendors lose regulated buyers that can't send data out.
- **Memory moves into the model.** If MemT-style in-layer memory works, standalone memory-API startups get squeezed. Build on the other side: tools to inspect, edit and delete what a model remembers (GDPR "forget me" for model state).
