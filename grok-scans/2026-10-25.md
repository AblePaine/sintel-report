## Ways to capitalize

- **Skills as the new distribution layer**: With SKILL.md under neutral AAIF and free multi-agent GitHub kits, the leverage is shipping *opinionated, production-hardened skills* (not another agent wrapper). Build vertical skill packs (e.g. regulated finance workflows, cloud cost optimization, compliance hooks) that install via `npx skills add` and work across Claude/Codex/Cursor. Displaces custom prompt engineering and single-vendor agent configs. Who loses: pure SaaS agent platforms that don't expose portable skills.
- **Cloud platforms as agent runtimes**: AWS toolkit makes AWS the default backend for coding agents. Opportunity: higher-level agent marketplaces or "agent CI/CD" that consume these skills + MCP, add governance/spend caps, and sell to enterprises. Or compete by exposing your own MCP + skills on other clouds (GCP/Azure equivalents). Displaces raw API wrappers.
- **x402 + card rails for agent payments**: Mastercard's early access validates machine-speed vouchers on open x402. Build agent identity + budget oracles, or micro-service endpoints that charge via x402 and settle through Mastercard/Base. Leverage for indie: sell paid MCP tools/skills with native agent payment. Displaces invoice-based SaaS and high-fee card rails for sub-dollar agent calls.
- **Open-weights near-frontier**: If Kimi claims hold, demand destruction hits closed frontier APIs for coding/agent tasks. Capitalize by fine-tuning/hosting the open model for agent workloads, or building eval/harness layers that quantify the gap. Who loses: pure API resellers without differentiation.
