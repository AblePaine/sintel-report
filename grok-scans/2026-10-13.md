## Ways to capitalize
- **Active Memory / long-horizon agents**: Meta just made persistent memory a product feature. Build agent harnesses that assume multi-day context (progress charts, goal files, night/morning skills) and sell them as "Claude/Muse overnight workers." Displaces one-shot chat tools.
- **x402 / agent-native payments**: Micro-payments for tools/APIs are live without accounts. Wrap any valuable MCP or API behind x402; agents become paying customers. Opportunity in discovery catalogs and reputation layers that agents query before paying.
- **Closed frontier + gated Full models**: Meta is not open-sourcing the good stuff. Leverage open small models (Gemma, Qwen) for the 95% System-1 routing, escalate only to paid frontier. Unit economics beat all-frontier loops.
- **Agent identity + escrow**: TermiX-style on-chain reputation is still early. Ship the lightweight version: agent DID + signed delivery proofs + simple escrow that works with existing USDC rails. Capture the M2M hire market before it consolidates.
- **Security harnesses**: Auto-approve is a liability. Productize allowlist-first coding agents or middleware that force confirmation on destructive actions. Indie devs already seeking the middle ground.
