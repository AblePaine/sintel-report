## Ways to capitalize

- **Agents with their own mailboxes are a new identity layer.** Muse giving every user an agent email address makes email the default way agents identify themselves to the outside world. Builders: an approval and audit layer for agent-sent mail, agent-to-agent mail protocols, and deliverability for agent senders. Expect spam filters to start sorting agent mail from human mail; whoever offers verified-agent sender reputation first owns that toll booth. **Displaced:** inbox-copilot plugins that only draft for a human.
- **Apple is turning the Mac into a walled garden for agents.** Fourteen steps to enable a rival agent means third-party computer-use on Macs becomes a power-user feature. The leverage moves to cloud computers built for agents (sub-second Linux VMs, like the Dedalus pitch AWS boosted this morning) and to Windows and Linux hosts. If your product is a local Mac agent, plan a cloud fallback now. Apple's own agent is a 2027 story; the friction is live today.
- **Tool catalogs just got cheap.** Gemini Tool Retrieval plus OpenAI's carried-over reasoning means agents can hold hundreds of tools without paying for every schema on every turn. That shifts the fight to discoverability: the short name and description are all the model sees before it loads a tool. MCP server builders should write tool descriptions like search ads. There's room for a "tool SEO" eval service, and for registries that rank servers by how often the model picks them correctly.
- **Hy4 is an open multimodal flagship with a system card.** The system card makes self-hosting defensible in regulated shops, such as finance research and game studios using Blender or Unity, which Tencent names. A builder can sell a hosted, fine-tunable Hy4 with private deployment and eval reports to buyers who can't send data to US labs or Chinese APIs. **Displaced:** per-token pricing on mid-tier closed multimodal APIs.
- **Nvidia buying inference speed.** If the Inception deal closes, Nvidia owns a non-autoregressive decoding stack it can tune for its own silicon. That means faster, cheaper tokens on standard GPUs, and less moat for custom inference-ASIC startups that sell on speed. Builders: latency-sensitive agent UX like voice and live coding gets cheaper first, so pair it with GPT-Live-class voice now.
- **GPUs as loan collateral need tracking.** The SpaceX covenant shows lenders treating chips as hard collateral that must stay reachable. There's room for GPU-backed lending infrastructure: serial-level location attestation, utilization proofs and insurance. It's niche but real money, as compute debt passes tens of billions per deal.
