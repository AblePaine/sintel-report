## Ways to capitalize

- **Quote-and-route layer on x402, not another paywall.** CoW just made a real DEX quote an HTTP 402 resource. The leverage is a thin agent that compares x402 quotes across venues (CoW, a chain-native AMM, a CEX API) and pays the cheapest one, with a hard spend cap like Cinder's. Displaces API-key aggregators and the human who refreshes a dashboard. Build the cap and the receipt log first; the model is commodity.
- **Sell verification, not the data.** Grift's demo pays for a decision trace that carries a proof against a ledger. The product to build is a generic "prove this agent did X" receipt that any x402 seller can attach — so buyers stop trusting the API. Whoever owns the receipt format taxes every agent-to-agent data sale.
- **Local-sign MCP as the default for anything that moves money.** Remote tool calls with a bearer token are how agents get drained. A local signer plus a per-call ceiling is the pattern exchanges, launchpads, and payroll tools will have to copy. Ship it as a library, not a memecoin.
- **Serving arbitrage under open weights.** If the model and the datacenter unbundle, the margin moves to whoever can serve a named open checkpoint cheaper and with a stable tool-calling API. Don't train. Wrap the checkpoint the labs just made swappable and undercut the closed endpoint on the one workload (quotes, classification, routing) agents actually loop.
- **Do not staff the $5–50m role.** That bid is labs buying distribution taste. Indie leverage is the opposite: a narrow agent surface (one paid MCP, one x402 endpoint) a lab's generalist agent will call. You get paid per call, they pay the operator.
