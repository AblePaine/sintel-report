Past 24h#

  • Agent commerce got its front door — and the money rail arrived the same week. Sierra + Meta published the Personal Agent Protocol (Oct 6): an OAuth-based open standard for how a personal agent authenticates with a business — guest/read-only/write tiers, sessions persisting across channels, merchant choice of website, APIs (MCP/OpenAPI), or its own agent. Founding partners: Shopify, Stripe, Walmart, Genesys, Instinct, Rocket (plus NiCE and Decagon per Meta's list). Absent: Amazon, OpenAI, Anthropic. v0.1 spec lands later in October; the payments extension is NOT in v0.1 even though Stripe is a founding partner. The rival: Visa's Trusted Agent Protocol (June) — 175M merchants, and Stripe and Shopify sit in both camps. The governance hole: eight logos, no license, no spec, no foundation yet. aiweekly · unite.ai · forkast
  • Alibaba Cloud x Sui: per-call stablecoin settlement for agents. Announced live Oct 7 at Sui Basecamp (Singapore, alongside TOKEN2049): Alibaba Cloud services reachable through Sui Agent Payments — an agent holds a stablecoin budget and pays per API call, settled on-chain. The ledger is the bill; no invoice. Same week Mysten unveiled Verifiable Agent Arbiter with Google Cloud — a system to check whether an agent stayed inside its permissions rather than trusting it. Actual agent adoption and volumes are not established by the announcement. startupfortune · phemex
  • OpenAI shipped the decision primitive: Decisions API in public beta (Oct 6). Typed answers over text/image inputs — probability, fixed choice, numeric score — claimed ~10x faster than the Responses API (~150ms), powered only by gpt-6-luna at $0.10/1M input tokens, output free, with zero-data-retention and HIPAA support. Same announcement: paid API tiers cut from five to three (Build / Launch / Grow; $500/$5k/$200k monthly usage limits). The quiet insight: stop using a chat completion as the control plane — a typed-decision endpoint folds parsing, confidence, and retries into the API contract. the-decoder · unite.ai · community.openai.com
