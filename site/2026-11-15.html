The FBI has published a flash alert on ARTEX — an open-source agent framework already running real intrusions#

  • FBI FLASH-20261113-001 (November 13) profiles ARTEX, an open-source, LLM-driven multi-agent penetration-testing framework that threat actors have weaponised since at least August 2026 across finance, government, technology, defence and energy — some intrusions reaching privileged access in under three hours. ARTEX ships no model of its own: it drives frontier models (Claude, GPT) and open ones (DeepSeek, GLM, Grok, Kimi), with Chinese-origin models most prevalent in attacker instances. The defensive detail worth keeping: the alert's indicators list LLM API endpoints as outbound traffic worth watching from servers that should never call them. Edge signal#

The permission layer froze this week — in five weeks it went from draft to default, and it is now the layer everything else must pass through. On October 9 the Personal Agent Protocol was a draft 0.1 that a portfolio audit could reasonably file as a cheap option. On November 13 it shipped as 1.0, Shopify switched it on for every store it hosts, and Meta's agent began reading the permission file before anything else on a site. Around it, in the same fortnight, the rest of the stack took shape: card networks issuing one-time tokens so agents never touch a card number, banks closing credential logins while protecting sanctioned channels, Socure preparing a verifiable credential that binds an agent to the human who authorised it, and an FBI alert showing what unpermissioned agent capability does to the soft long tail of the internet. Every one of those is the same invention from a different side — a named issuer, a scoped grant, a check at the threshold, a record afterwards. Capability is abundant and getting cheaper; models are repricing toward zero at every layer. What is scarce, standardising and starting to charge is verifiable permission. The builds positioned for this are the ones that already speak the permission protocols — a discovery file in place, scoped tools behind it, an audit trail under it — and the ones that, by design, need no permission at all because they never act on anyone's money, data or storefront. Both positions were available cheaply this year. After this week, only one of them still is.
