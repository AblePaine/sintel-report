Prove which model answered — Anthropic open-sources FlashProve#

  • Anthropic released FlashProve on November 2, an open-source (Apache 2.0) research prototype for provable inference: a provider commits to one exact set of weights, and each response carries a zkSNARK proof that those committed weights produced it, without revealing the weights. Tested on Llama 4 Maverick (400B MoE, 4-bit), proof generation ran at about 110 tokens per second on one H100 — at roughly 70–95× the GPU cost of running the model itself — with proofs of about 19 MB per 1,024-token request, checkable on a CPU in about 17–21 seconds. Anthropic is explicit that this is a research artifact, not a product, with no deployment plans stated. The problem it names is real regardless: today, a hosted answer carries no evidence of which model actually produced it. Unite.AI · Blockchain.News

Weight-space programming — a frontier model patched an open model by hand, with an honest asterisk#

  • MIT CSAIL researchers published "weight-space programming" on November 2 (about 6.7M views on the lead post): GPT-6 Astra inspected Qwen3.5-0.8B's raw weights and, with no training and no gradients, edited 131,072 of them — 0.016%, in two layers — lifting MATH-500 from 7.9% to 48.1% and GSM8K from 13.8% to 67.1%. The asterisk matters and the authors state it: the edit removed a repetition direction that trapped the model in thinking loops (answers hitting the token limit fell from 93% to 33.1%); it repaired an obstruction rather than teaching new math. An independent re-check found that with thinking off, the unedited model already scores 43.6% and the edit adds only about 1.6 points — and on Gemma, which rarely loops, the same approach gained nothing. The durable finding is narrower and still significant: a model can read another model's weights, diagnose a failure mode, and patch it directly. VentureBeat · HedwigAI — independent re-check
