Build for the agents — the desktop and the skill become callable surfaces#

  • Vercel Labs open-sourced agent-desktop (v1.0.2, October 30, Apache-2.0): a Rust CLI and C library that gives any shell-capable coding agent computer use on macOS, Windows, and Linux by reading the OS accessibility tree — a JSON snapshot with a stable ref per element — instead of screenshots and pixel coordinates. It runs headless without moving the pointer, supports several agents on one app, and pairs with agent-browser and Vercel Sandbox. Builder-reported token savings of 78–96% on dense apps are self-reported, with no independent computer-use benchmark yet; apps that expose no accessibility tree remain out of reach. MarkTechPost
  • OpenAI's Python SDK 3.42.0 (October 31) moved Agents API context compaction into client-side configuration (background or blocking), and added session review, agent tool settings, experimental time awareness, and organization external key management. The direction matters more than the version number: compaction, review gates, and time budgets are becoming explicit, configurable parts of the agent runtime contract rather than opaque server behavior. AI Weekly
  • Skills-over-MCP dating correction: the Gemini lane flagged SEP-2640 as newly standardized — the spec has been Final since September 13. What is actually new is implementation: the MCP TypeScript SDK 2.4.0 (October 23) ships the extension, letting a server serve both its tools and the SKILL.md instructions for using them under `skill://` URIs, with per-skill approval and digest binding. Adoption is still near zero — a recent sweep found only 2 of 572 reachable hosted MCP servers declaring the extension. The standard is settled; the servers are the open field. SEP-2640 spec · API Evangelist
  • Microsoft Research and UC Berkeley's TokenEconomizer kept spreading (code released October 26, pickup this week): a plugin for Claude Code, Codex, Copilot CLI, and Pi that learns repo facts, prunes unused tools, and breaks failure loops, with a paper reporting 18.4–30.9% lower mean cost across 277 SWE-Bench tasks. Vendor-adjacent research, not independently reproduced — but cost control for agent loops is now a named product shape with a paper attached. (From the Grok scan; GitHub: microsoft/TokenEconomizer.)

Robotics — the Covered List gets its first humanoid exemption#

  • Lightberry announced (October 30) that its Lumi humanoids received Department of War Conditional Approval and an FCC exemption from the Covered List — the July 28 listing that blocks new FCC authorization for foreign-produced advanced robotic devices — making it, by its account, the first and so far only humanoid company cleared. The price of clearance is the template: replace sensors, onboard compute, and software with its own stack, and manufacture body, head, and hands in the US, with the rest to follow. The underlying ban context is real and broad — Chinese makers held an estimated 97% of global humanoid shipments in H1 2026, and previously authorized models keep selling, so the wall applies to the next generation, not the installed base. Company announcement; the FCC public notice (DA 26-1181) is cited in it. Lightberry

Edge signal of the day#

  • Capital became the gatekeeper. For three years the scarce thing was capability, then compute. This week the scarce thing repriced: OpenAI's round shrank on its own deadline, Amazon collateralized its hardware, Meta's credit outlook turned on an agent product with 10 million setups and no proven business model, and Anthropic heads into a November listing at a cut price with a possible junk rating attached. The labs will keep shipping — but on lenders' and public markets' terms now, which means margin protection: higher prices, tighter tiers, more tolls on the hosted layer. Every one of those tolls is demand destruction for rented AI and a relative gain for the side that owns its weights, owns its distribution, and never has to fill a round. The edge is no longer getting access to the frontier first. It is needing the frontier least.
