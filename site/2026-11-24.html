Past 24h overview#

  • The agent gateway became the default architecture — in one day, from three directions at once. Google made its Workspace MCP servers and Workspace CLI generally available and set a hard date: from February 1, 2027, AI agents must reach Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks through those managed interfaces instead of REST APIs, with dedicated OAuth client IDs, least-privilege scopes, per-request policy/DLP checks, and quota billing starting April 1, 2027. Walmart's Agent Gateway went live the same day with Meta's Muse as first agent (see below). And Canva opened its MCP server to everyone (see below). Three unrelated platforms, one pattern: agents no longer browse or call like humans — they enter through a named, scoped, auditable gateway, or they don't enter at all. (Unite.AI, AIP Guard)
  • Walmart–Muse shopping is live for Black Friday. After a 24-hour delay, the Agent Gateway opened to Meta's Muse on November 24: shoppers link a Walmart account inside Muse, the first cart item creates a scoped Agent Profile, and purchases run under a customer-set spending cap with per-purchase approval and a separate agent purchase history — at Walmart.com prices, with card details never exposed to the agent. Amazon and eBay continue to block agents outright. Muse also launched in the UK today, extending the same agent surface to a second major market in one day. (BigGo Finance, Roori)
  • Anthropic shipped the merge button: Claude Ship (beta). The suite bundles Code Review (GA) with two new beta agents for Team and Enterprise GitHub repos — PR Steward, which fixes failing CI, merge conflicts and review feedback (and never approves), and Claude Approvals, which reads a team-written policy file in the repo and can approve routine PRs on its own, escalating the rest to humans. Anthropic recommends observe-only mode first and says its own Claude Code team more than doubled merged PRs June–September. The bottleneck agents created — more code than humans can review — is now being solved by delegating the approval itself, under a written policy. (TechCrunch, The Register)
  • Claude's skills and connectors merged into one Plugins system — 10,000+ add-ons, free tier included. Announced November 23, the unified Plugins page replaces the separate Skills, Connectors and Plugins tabs; a plugin can bundle skills, connectors, commands, hooks and sub-agents into a single installable package. Live on Free, Pro, Max and Ultra, with Team and Enterprise following (the Skills-off admin rule bites November 30). Tool access and procedural know-how now ship as one product — the app-store shape for agent capability. (Claude Help Center, dev.to)

The 280B-total / 14B-active MoE with a 1M-token context is now downloadable from Hugging Face and ModelScope in FP4-expert, FP8 and BF16 builds, free on OpenRouter as well. Two honest caveats: Baidu itself calls it an intermediate checkpoint with post-training still running, and the Apache 2.0 grant covers the Preview only — the Base checkpoint stays under Baidu's own license, which excludes the EU, UK and South Korea. Even so: a permissively licensed, self-hostable 1M-context MoE at Flash-class cost is a direct undercut of paid long-context APIs. (Times of AI, Superpower Daily)

Edge signal#

Agent access stopped being a feature and became a border — with customs posts, papers, and an enforcement date. Until this week, an agent reached software the way a person did: a login, a browser, an API key. In a single day that era got its closing paperwork from three directions at once. Google announced that from February 1, 2027, agents reach Workspace only through managed MCP gateways, carrying dedicated identities, least-privilege scopes, and per-request policy checks — with a meter attached from April 2027. Walmart opened its gateway to Muse under scoped Agent Profiles with spending caps and per-purchase approval, timed for the biggest shopping week of the year. Canva removed its waitlist and rebuilt its server around how agents actually choose tools. None of these is a model release; all three are border infrastructure, and borders are where the durable money in any new economy collects — not in the travelers, but in the crossings: identity, permission, policy, audit. The platforms are building their own crossings and will charge for them. The open ground is the same ground identified yesterday, now with a deadline on it: crossings that small operators own — portable agent identity, self-hosted gateways, policy layers that answer to the operator instead of the platform. February 1, 2027 is the first hard date on that calendar, and the build window runs from now to then.
