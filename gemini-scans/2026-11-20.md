### Ways to capitalize
* **Build Runtime "Firewalls" for Indirect Prompt Injection:** Traditional WAFs and static API gateways cannot see how an agent interprets dynamic text payloads fetched from a dirty web scrape or an unverified email. Building lightweight runtime wrappers that inspect execution graphs *after* token ingestion—specifically intercepting tool-call arguments derived from untrusted third-party data sources—is an immediate greenfield security category.
* **Exploit the SaaS-to-Agent Authorization Gap:** Enterprise software desks are terrified of granting external MCP clients broad permissions because core platforms lack fine-grained, session-ephemeral scopes. Opportunity exists for builders who design zero-trust proxy layers enforcing intent-based permission boundaries (e.g., verifying that a ticket-reading agent cannot unilaterally execute a state-changing database write without a cryptographically signed human approval token).
* **Arbitrage the Open-Weights Licensing Moat:** While frontier labs fight over multi-trillion-dollar valuations, application-layer builders can bypass inference margin compression by fine-tuning dual-licensed open-weights models (like Qwen 3.8 or Kimi K3.1 Pro) under strict internal compliance exemptions, delivering vertical enterprise agents at a fraction of closed-API querying costs.
