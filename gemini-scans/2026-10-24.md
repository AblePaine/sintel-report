# Gemini morning scan — 2026-10-24

* **Anthropic Donates Agent Skills to AAIF**: Anthropic handed its open `Agent Skills` standard (powering over 1 million published modules across IDEs and agent platforms) over to the Linux Foundation’s [Agentic AI Foundation (AAIF)](https://www.linuxfoundation.org/press/agentic-ai-foundation-expands-with-four-open-source-projects), alongside OpenAI’s contribution of `Open Responses` to normalize API templates. 
* **Microsoft Introduces "Work IQ" Retrieval Tool**: Microsoft rolled out an enterprise-grade Model Context Protocol (MCP) tool that searches internal emails, Teams messages, and documents, returning structured source records and model-ready Markdown complete with inline citations.
* **Ransomware Affiliates Weaponize MCP Servers**: Cybersecurity researchers at Symantec and The Hacker News revealed that active threat groups are deploying custom "WormGPT-MCP" server sets—connecting automated agent loops to 32 discrete modules for target reconnaissance and extortion planning.
* **LLMjacking Vectors Exploit Unprotected AI Gateways**: Security audits highlighted a surge in attacks where threat actors hijack open model endpoints or default MCP gateways, executing up to 100,000-step autonomous hacking sequences on the victim's compute budget.
* **OpenAI Targets $1.25 Trillion Valuation**: Reports surfaced that OpenAI is in the final stages of structuring a massive new funding round seeking roughly $30 billion, pushing its private valuation marker to $1.25 trillion.
* **Dream Labs Emerges from Stealth with Physical AI Playground**: Ex-Nvidia robotics researchers launched Dream Labs with a $90M seed round, opening a public API that lets developers remotely rent time on physical robotic arms in a San Francisco "robot playground".

### Ways to Capitalize

* **Build Enterprise Security Wrappers for MCP Gateways**: With threat actors actively performing "LLMjacking" and hijacking exposed local Model Context Protocol servers to run unsupervised exploit loops, every enterprise adopting agent tools desperately needs runtime proxy firewalls. Build authorization, rate-limiting, and semantic validation proxies that sit between local LLMs/MCP clients and external tool servers to intercept malicious multi-step command sequences before execution.
* **Launch Standardized "Agent Skills" Packaging and Audit Pipelines**: Now that Anthropic’s `Agent Skills` and OpenAI's `Open Responses` are unified under the neutral governance of the AAIF, developers face a modular integration gold rush. Build CI/CD pipelines and static analysis security linters designed explicitly to validate, sanitize, and optimize `SKILL.md` folders and automated scripts before teams deploy them into production agent runtimes.
* **Arbitrage Remote Physical AI Infrastructure**: Dream Labs proving massive immediate demand for hourly remote access to physical robot arms demonstrates that software developers want to test embodied AI without buying hardware. Capitalize by building localized simulation-to-reality validation layers or localized orchestration software that helps small robotics labs rent out their idle hardware capacity overnight.
