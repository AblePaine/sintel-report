## Ways to capitalize
- **Neocloud distress is a buying window, not just a headline.** If Musk is right that credit is shut for AI-only revenue, expect forced GPU sales and lease assignments in H1 2027. Build the secondary market: lease transfer, utilization-backed valuation, and brokered capacity for inference startups that can't get debt. Sellers of "AI-only" compute get displaced by anyone with diversified revenue.
- **Agent workspace hygiene is a product now.** "Don't run agents in Downloads" won't survive contact with real users. Sell a launcher or pre-flight check that refuses untrusted instruction files (AGENTS.md, CLAUDE.md, SKILL.md), diffs agent config for new MCP servers or base-URL changes, and alerts on token exfil. Fits enterprise endpoint vendors as a feature, or indie as a CLI plus team dashboard.
- **Websites-as-MCP is the long-tail integration layer.** Pomerado's wedge (legacy portals with no API) is the same land grab Plaid ran for banks. A builder can pick one vertical (payer portals, freight brokers, county records), own the maintained tool catalog, and charge per successful action; browser-use agent vendors lose the "it works anywhere" pitch.
- **Retailers are building walled agent gardens.** Walmart routing agents through Sparky says retailers want agent traffic but not agent control of the wallet. The opening is on the buyer side: a neutral agent that holds the user's budget and preferences and negotiates across retailer agents, plus the local-scheme rails Europe is now organizing around.
