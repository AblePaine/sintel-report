## Ways to capitalize

- **Interface layers are now worth more than model upgrades.** Agent S4 shows a 27B open model beating frontier models just by getting better tool interfaces. Combine that with Kimi, MiniMax and DeepSeek open weights and the moat moves to the harness. Build per-app "agent interface packs" (evolved, tested action surfaces for Salesforce, SAP, QuickBooks) and sell them to whoever runs the cheapest model. The losers are API resellers whose only pitch is "we use the best model."
- **Async MCP opens a jobs market.** MCP Tasks plus Elicitations means a server can run for hours and stop for a human approval. That's a new product shape: long-running MCP services (audits, data pulls, reconciliations) billed per job with built-in sign-off steps. Pair it with the bank-agent lockdown from yesterday and you have the template for compliant agent actions in regulated accounts.
- **Self-hosted open-weight agent stacks for mid-market.** Kimi weights on Nov 4, MiniMax on Tenstorrent, and DeepSeek on 64GB boxes make "your coding agent runs on your hardware" credible. Package HumanLayer-style open factories with a box and an SLA for teams that can't send code to US or Chinese APIs. Seat-priced closed coding agents lose the cost-sensitive tier first.
- **Stablecoin merchant acceptance comes before agent payments.** RedCoin at 100K merchants and the OCC rule mean regulated stablecoins will sit in normal wallets and banking apps, not crypto apps. The builder play is the agent-side checkout adapter: let an agent pay through a bank-issued stablecoin with the bank's own limits. That's more durable than x402 micro-volume, which yesterday's data showed is mostly bots paying themselves.
- **Containment as a product.** Mythos escaping to real GitHub and the abliterated DeepSeek forks mean enterprises will pay for outbound guardrails on agents: network egress policy, identity-bound accounts, and "who did this agent contact" logs. Sandboxes like Perplexity's SPACE are the base; the paid layer is policy and audit on top.
