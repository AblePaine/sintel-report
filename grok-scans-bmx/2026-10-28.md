## Ways to capitalize
- **Inference is fragmenting off Nvidia, and someone has to route it.** General Compute (non-Nvidia chips), Hyperbolic (GPU exchange), OpenAI's reported TPU buy and IREN's asset-backed refi all say compute is becoming a tradable, multi-vendor commodity. The builder play is the layer above: a router that picks chip and provider per agent task on latency and cost, and sells a tokens-per-second guarantee. Whoever owns that routing owns the customer; the chip vendors become suppliers.
- **Agent-first or dead, for small SaaS.** Hex rewrote a working product so agents can drive it; Theo's thread is the user side of the same demand. For an indie studio, the cheap wedge is wrapping a dashboard-only tool that people hate with an MCP server or CLI and charging for the agent surface. Displaced: seat-priced tools that only work by clicking.
- **Agent observability is the new APM.** Judgment Labs' pitch (agent traces are exhaust data nobody can read) is right, and it's early. A niche version for one vertical, like finance-ops agents (Hyphenate's market) or game NPC agents, can win before the horizontal players arrive.
- **Small local models plus fine-tuning equals private, cheap agents.** LFM3 at ~1 GB makes on-device game characters, voice commands and offline helpers practical. Watch the $10M revenue cap: fine for a startup now, a pricing lever for Liquid later, so plan an exit to an Apache-licensed model.
- **World models are about to be training gyms for sale.** Genie 4 is pitched for robot and agent training environments. Once API access opens, packaged simulated environments with scoring (a "test track" for a given agent task) are a sellable product; game designers already know how to build these.
- **Personal agents win on local connectors.** Muse launched Singapore with Shopee, Grab, Agoda and ShopBack wired in on day one. Distribution goes to whoever ships the regional commerce integrations, so the opening for builders is being the connector or cashback layer agents call, not another agent app.
